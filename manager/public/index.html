自动配置

  1. 打开 Cloudflare → API 令牌，点击「创建令牌」→「创建自定义令牌」。
  2. 添加权限：帐户 · Cloudflare Tunnel · 编辑、帐户 · 帐户设置 · 读取、区域 · DNS · 编辑、区域 · 区域 · 读取。
  3. 把生成的令牌粘贴到下面，点击「验证并读取域名」。

隧道令牌

  1. 在 Cloudflare Zero Trust → 网络 → 隧道，创建一个 Cloudflared 隧道。
  2. 在隧道的「路由 → 添加路由 → 已发布的应用程序」（旧版界面叫「公共主机名」）中添加你的域名，服务填 http://sharelatex:80。注意是 http 不是 https，主机是 sharelatex 不是 localhost。
  3. 在隧道「概览」页的安装命令里，复制 --token 后面的那一串，粘贴到下面，并在「公网域名」填同一个域名。
